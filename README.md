# Magic Hour Scoop bucket

Add the bucket, then install stable `mh` on Windows:

```powershell
scoop bucket add magic-hour https://github.com/magichourhq/scoop-bucket
scoop install magic-hour/mh
```

To try preview releases, install `mh-dev` from the same bucket:

```powershell
scoop install magic-hour/mh-dev
```

`mh` and `mh-dev` can be installed side by side.
